# Алгоритмы

## 1. Тайлинг WSI (`src/wsi/tiler.py`)

Гигапиксельный препарат (~100 000 × 100 000 px) не помещается в память модели целиком. Пайплайн «разделяй и анализируй»:

1. **Пирамида разрешений.** `WsiReader` (`src/wsi/reader.py`) читает нужный уровень/регион через OpenSlide, не загружая файл целиком.
2. **Миниатюра для маски тканей.** Читается уменьшенная копия препарата (даунсемпл, `wsi.tissue_mask_level_downsample` в конфиге, по умолчанию 32×) — на неё быстро считается маска тканей (см. §2).
3. **Сетка тайлов.** Препарат нарезается на тайлы `wsi.tile_size × wsi.tile_size` (по умолчанию 256×256) с шагом `wsi.tile_stride`, координаты — в системе уровня 0.
4. **Отбор по маске.** Для каждого потенциального тайла соответствующая область маски тканей проверяется на долю ткани (`_tile_has_tissue`); тайл добавляется в план только если доля ≥ `preprocessing.min_tissue_fraction`. Так тайлы, целиком попадающие на пустое стекло, никогда не читаются в полном разрешении и не проходят через модель.
5. **Ленивое чтение.** `iter_tile_images()` читает по одному тайлу за раз (генератор) — пиковое потребление памяти не растёт с размером препарата.

## 2. Фильтрация фона (Otsu) (`src/preprocessing/tissue_filter.py`)

60–80% площади WSI — пустое стекло. Отличить ткань от фона можно по каналу насыщенности (S) в HSV: окрашенная H&E ткань высоко насыщена, стекло/фон — почти нет.

Порог между двумя классами (ткань/фон) определяется автоматически методом **Оцу (Otsu, 1979)**: перебираются все возможные пороги `t` канала насыщенности, и выбирается тот, что минимизирует внутриклассовую дисперсию (эквивалентно — максимизирует межклассовую):

```
σ²_between(t) = w_bg(t)·w_tissue(t)·(μ_bg(t) − μ_tissue(t))²
t* = argmax_t σ²_between(t)
```

где `w`, `μ` — доля пикселей и средняя насыщенность каждого класса при пороге `t`. Реализация — `cv2.threshold(..., cv2.THRESH_OTSU)`. Порог можно зафиксировать вручную через `preprocessing.tissue_saturation_threshold` в конфиге, если авто-порог для конкретного сканера работает нестабильно.

## 3. Нормализация окраски — метод Macenko (`src/preprocessing/stain_normalization.py`)

H&E-окраска визуально различается между лабораториями/сканерами (разные реагенты, время окрашивания, цветопередача сканера). Без нормализации это создаёт domain shift, к которому модель чувствительна. Реализован метод **Macenko et al., 2009** (SVD-разложение в пространстве оптической плотности), без внешней зависимости `staintools` — своя реализация даёт полный контроль и не требует нативных сборок (проблематично на Windows), что важно для аудируемости медицинского ПО.

**Шаг 1 — оптическая плотность (закон Бера-Ламберта).** Для RGB-пикселя `I`:

```
OD = -log10((I + 1) / 256)
```

(`+1` избегает `log(0)` на чисто белых пикселях).

**Шаг 2 — отсечение фона.** Пиксели с OD ниже порога `β = 0.15` по всем каналам считаются фоном/стеклом и исключаются из оценки красителей.

**Шаг 3 — оценка направлений красителей (SVD/PCA-плоскость).** Строится ковариационная матрица OD оставшихся (тканевых) пикселей, берутся два собственных вектора с наибольшей дисперсией — плоскость, в которой лежит почти вся вариация окраски. Тканевые OD-точки проецируются на эту плоскость, для каждой считается угол `atan2(y, x)`.

**Шаг 4 — робастные крайние направления.** Берутся `α`- и `(100-α)`-й процентили угла (`α = 1`, устойчиво к выбросам) — это направления гематоксилина и эозина. Порядок определяется по величине красной компоненты OD (гематоксилин даёт более высокую).

**Шаг 5 — концентрации красителей.** Для каждого пикселя решается МНК-система:

```
OD_pixel = StainVectors · C   →   C = lstsq(StainVectors, OD_pixel)
```

**Шаг 6 — перенормировка на референсный профиль.** Концентрации масштабируются по 99-му процентилю (устойчиво к выбросам) исходного изображения и профилю референсных красителей/максимальных концентраций (`preprocessing.macenko_reference` в конфиге — фиксированный стабильный H&E-профиль):

```
C_norm = C / percentile99(C) · C_ref_max
OD_norm = C_norm · StainVectors_ref
I_norm = 256 · 10^(-OD_norm) − 1
```

Если после отсечения фона в тайле остаётся слишком мало тканевых пикселей (< 50) — нормализация не выполняется, изображение возвращается без изменений (шум на почти пустом тайле хуже, чем отсутствие нормализации).

## 4. Классификатор

- **Архитектура:** EfficientNet-B3 (`timm`), 2 класса (доброкачественная/злокачественная).
- **Обучение:** датасет BreakHis (n=7909), см. [MODEL.md](MODEL.md).
- **Препроцессинг на инференсе:** resize до 224×224, нормализация по статистикам ImageNet — идентично протоколу обучения (`src/inference/classifier.py`).
- **Вывод:** softmax по 2 классам → вероятности + уверенность (`max(softmax)`).

## 5. GradCAM++ (`src/xai/gradcam.py`)

Explainability-метод **GradCAM++ (Chattopadhyay et al., 2018)** — обобщение GradCAM с точными весами пиксельного вклада через вторые производные, даёт более чёткую локализацию при нескольких объектах интереса на изображении (типично для гистологии — несколько атипичных очагов). Хук ставится на последний свёрточный блок EfficientNet-B3 (`model.blocks[-1][-1]`, как в исходном прототипе) — это финальные признаки перед классификационной головой, где пространственная карта активации ещё сохраняет соответствие с исходным изображением, а семантика уже максимально приближена к решению модели.

Тепловая карта `grayscale_cam ∈ [0,1]^{H×W}` накладывается на изображение (`show_cam_on_image`) для визуализации и используется для извлечения зон внимания (§6).

## 6. Топ-K зон внимания (`src/xai/regions.py`)

1. Порог = `0.5 × max(cam)` (`xai.region_threshold_ratio`) — оставляет только зоны, близкие к пиковой активации.
2. Бинарная маска размечается на связные компоненты (`scipy.ndimage.label`).
3. Компоненты меньше `xai.min_region_pixels` (по умолчанию 4 px) отбрасываются как шум.
4. Оставшиеся ранжируются по средней активации внутри компоненты, возвращаются топ-K (`xai.top_k_regions`, по умолчанию 3) с координатами ограничивающего прямоугольника и оценкой значимости.

## 7. Агрегация по всему препарату (`src/inference/wsi_aggregator.py`)

Каждый прошедший фильтр тайл классифицируется (батчами, `wsi.batch_size`) и получает вероятность злокачественности. Вердикт всего препарата — **среднее по верхнему децилю тайлов** по вероятности злокачественности:

```
P_slide = mean(sorted(P_tiles)[-⌈N/10⌉:])
```

Обоснование: один сильно атипичный очаг должен определять вердикт, а не растворяться в среднем по тысячам обычных тайлов — это соответствует тому, как патологоанатом просматривает препарат (ищет наиболее подозрительные поля, а не усредняет впечатление по всему стеклу). Топ-3 «зоны внимания» для WSI — это координаты тайлов с наибольшей вероятностью злокачественности (аналог GradCAM-зон, но на уровне тайлов, а не пикселей одного патча — прогон GradCAM++ на каждом из тысяч тайлов не уложился бы в целевое время на CPU).

Тепловая карта всего препарата — вероятность злокачественности каждого тайла, отрисованная на миниатюре (`cv2.COLORMAP_JET`, синий = низкая, красный = высокая значимость) и наложенная полупрозрачным слоем на исходное изображение ткани.
