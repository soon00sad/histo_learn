# Алгоритмы

> Эта версия (`feature/segmentation`) заменяет §4–7 ниже: вместо бинарного
> классификатора с GradCAM++ — попиксельная сегментация тканей со сшивкой
> перекрывающихся тайлов в единую маску препарата. §1–3 (тайлинг, фильтрация
> фона, нормализация Macenko) переиспользуются без изменений — сегментация
> использует свою секцию конфигурации (`segmentation_wsi`) с другими
> значениями `tile_stride`/`tile_size`, но тот же код.

## 1. Тайлинг WSI (`src/wsi/tiler.py`)

Гигапиксельный препарат (~100 000 × 100 000 px) не помещается в память модели целиком. Пайплайн «разделяй и анализируй»:

1. **Пирамида разрешений.** `WsiReader` (`src/wsi/reader.py`) читает нужный уровень/регион через OpenSlide, не загружая файл целиком.
2. **Миниатюра для маски тканей.** Читается уменьшенная копия препарата (даунсемпл, `wsi.tissue_mask_level_downsample` в конфиге, по умолчанию 32×) — на неё быстро считается маска тканей (см. §2).
3. **Сетка тайлов.** Препарат нарезается на тайлы `wsi.tile_size × wsi.tile_size` (по умолчанию 256×256) с шагом `wsi.tile_stride`, координаты — в системе уровня 0.
4. **Отбор по маске.** Для каждого потенциального тайла соответствующая область маски тканей проверяется на долю ткани (`_tile_has_tissue`); тайл добавляется в план только если доля ≥ `preprocessing.min_tissue_fraction`. Так тайлы, целиком попадающие на пустое стекло, никогда не читаются в полном разрешении и не проходят через модель.
5. **Ленивое чтение.** `iter_tile_images()` читает по одному тайлу за раз (генератор) — пиковое потребление памяти не растёт с размером препарата.

## 2. Фильтрация фона (Otsu) (`src/preprocessing/tissue_filter.py`)

60–80% площади WSI — пустое стекло. Отличить ткань от фона можно по каналу насыщенности (S) в HSV: окрашенная H&E ткань высоко насыщена, стекло/фон — почти нет.

Порог между двумя классами (ткань/фон) определяется автоматически методом **Оцу (Otsu, 1979)**: перебираются все возможные пороги `t` канала насыщенности, и выбирается тот, что минимизирует внутриклассовую дисперсию (эквивалентно — максимизирует межклассовую):

```
σ²_between(t) = w_bg(t)·w_tissue(t)·(μ_bg(t) − μ_tissue(t))²
t* = argmax_t σ²_between(t)
```

где `w`, `μ` — доля пикселей и средняя насыщенность каждого класса при пороге `t`. Реализация — `cv2.threshold(..., cv2.THRESH_OTSU)`. Порог можно зафиксировать вручную через `preprocessing.tissue_saturation_threshold` в конфиге, если авто-порог для конкретного сканера работает нестабильно.

## 3. Нормализация окраски — метод Macenko (`src/preprocessing/stain_normalization.py`)

H&E-окраска визуально различается между лабораториями/сканерами (разные реагенты, время окрашивания, цветопередача сканера). Без нормализации это создаёт domain shift, к которому модель чувствительна. Реализован метод **Macenko et al., 2009** (SVD-разложение в пространстве оптической плотности), без внешней зависимости `staintools` — своя реализация даёт полный контроль и не требует нативных сборок (проблематично на Windows), что важно для аудируемости медицинского ПО.

**Шаг 1 — оптическая плотность (закон Бера-Ламберта).** Для RGB-пикселя `I`:

```
OD = -log10((I + 1) / 256)
```

(`+1` избегает `log(0)` на чисто белых пикселях).

**Шаг 2 — отсечение фона.** Пиксели с OD ниже порога `β = 0.15` по всем каналам считаются фоном/стеклом и исключаются из оценки красителей.

**Шаг 3 — оценка направлений красителей (SVD/PCA-плоскость).** Строится ковариационная матрица OD оставшихся (тканевых) пикселей, берутся два собственных вектора с наибольшей дисперсией — плоскость, в которой лежит почти вся вариация окраски. Тканевые OD-точки проецируются на эту плоскость, для каждой считается угол `atan2(y, x)`.

**Шаг 4 — робастные крайние направления.** Берутся `α`- и `(100-α)`-й процентили угла (`α = 1`, устойчиво к выбросам) — это направления гематоксилина и эозина. Порядок определяется по величине красной компоненты OD (гематоксилин даёт более высокую).

**Шаг 5 — концентрации красителей.** Для каждого пикселя решается МНК-система:

```
OD_pixel = StainVectors · C   →   C = lstsq(StainVectors, OD_pixel)
```

**Шаг 6 — перенормировка на референсный профиль.** Концентрации масштабируются по 99-му процентилю (устойчиво к выбросам) исходного изображения и профилю референсных красителей/максимальных концентраций (`preprocessing.macenko_reference` в конфиге — фиксированный стабильный H&E-профиль):

```
C_norm = C / percentile99(C) · C_ref_max
OD_norm = C_norm · StainVectors_ref
I_norm = 256 · 10^(-OD_norm) − 1
```

Если после отсечения фона в тайле остаётся слишком мало тканевых пикселей (< 50) — нормализация не выполняется, изображение возвращается без изменений (шум на почти пустом тайле хуже, чем отсутствие нормализации).

## 4. Сегментационная модель (`src/inference/segmenter.py`)

- **Архитектура:** DeepLabV3+ (`segmentation_models_pytorch`), энкодер ResNet-18, 16 классов тканей BCSS (см. [MODEL.md](MODEL.md) для полной таксономии и обоснования выбора архитектуры).
- **Обучение:** датасет BCSS, `src/training/` (см. MODEL.md, «Как обучить»).
- **Препроцессинг на инференсе:** resize до 256×256, нормализация по статистикам ImageNet — идентично протоколу обучения.
- **Вывод:** softmax по 16 классам на каждый пиксель входного патча → argmax даёт класс-карту `[H, W]`; для одного патча (`PatchSegmenter.segment`) дополнительно считаются доли площади по классам и средняя уверенность (`mean_confidence` = средний `max(softmax)` по пикселям) — не для вердикта, а как индикатор качества самого прогноза (см. MODEL.md про низкую наблюдаемую уверенность текущего чекпоинта).

## 5. Сшивка тайлов WSI в единую маску (`src/inference/wsi_segmenter.py`)

В отличие от бинарного пути (§7 старой версии, без перекрытия — один скаляр на тайл, откуда для тепловой карты сеточные артефакты не критичны), сегментационные тайлы **перекрываются**: `segmentation_wsi.tile_stride` (128) меньше `segmentation_wsi.tile_size` (256) — 50% перекрытие. Наивное сшивание пиксельных предсказаний соседних тайлов без учёта перекрытия даёт заметные швы на границах (известный артефакт patch-wise инференса CNN на больших изображениях) — устраняется взвешенным blending'ом:

1. **Аккумулятор вероятностей.** Для всего препарата заводится canvas `[num_classes, H_canvas, W_canvas]` (даунсемплированный от уровня 0 в `segmentation_wsi.mask_output_downsample` раз — полноразрешённый canvas для гигапиксельного препарата не влезет в память) плюс canvas весов `[H_canvas, W_canvas]`.
2. **2D-окно Ханна (Hann window).** Каждый тайл имеет собственную весовую маску — максимальный вес в центре тайла, плавно спадающий к нулю на краях (`hann_window()`): `w(i,j) = hann(i) · hann(j)`, где `hann(n) = 0.5(1 − cos(2πn/(N−1)))`. Вес обрезается снизу на `1e-3`, чтобы тайл без соседей на краю тканевой области всё равно вносил вклад.
3. **Накопление (`accumulate_tile()`).** Вероятностная карта каждого тайла даунсемплируется до масштаба canvas и добавляется в аккумулятор вероятностей с весом окна Ханна; тот же вес добавляется в аккумулятор весов. Соседние тайлы автоматически усредняются пропорционально удалённости от своего центра — граница между ними становится плавным переходом, а не резким скачком класса.
4. **Финализация (`mask_from_accumulators()`).** После обработки всех тайлов: `mask = argmax(prob_accum, axis=classes)` по пикселям, где вес > 0. Пиксели, которые не покрыл ни один тайл (фон/стекло, отфильтрованный ещё на этапе тайлинга — §2), получают сигнальное значение `UNCOVERED = 255`, а не `0` — индекс `0` соответствует реальному классу `tumor`, и присвоение его непокрытым пикселям молча выдавало бы их за предсказание опухоли.

## 6. Агрегация по классам и вердикт (`src/inference/verdict.py`)

Финальная маска даёт долю площади каждого класса `fraction[c] = count(mask == c) / count(covered)` — только по покрытым тканью пикселям, `UNCOVERED` в знаменатель не входит. Это единая логика для одного патча (`PatchSegmenter.segment`) и целого препарата (`analyze_wsi_segmentation`) — обе выдают одинаковый по форме `dict[name_en, fraction]`.

Вердикт («злокачественная»/«доброкачественная») — не отдельная модель, а порог по совокупной площади классов из `segmentation_verdict.malignant_class_names` (по умолчанию `tumor` + `dcis`, `angioinvasion` уже включён в `tumor` на этапе группировки классов — см. MODEL.md):

```
tumor_area_fraction = Σ fraction[c] for c in malignant_class_names
verdict = "Злокачественная" if tumor_area_fraction ≥ segmentation_verdict.malignant_area_threshold (0.01) else "Доброкачественная"
```

Порог намеренно низкий (1% площади, не «большинство класса») — небольшой инвазивный/DCIS-очаг на фоне в остальном доброкачественного препарата всё равно диагностически значим; это тот же принцип, что определял агрегацию по верхнему децилю тайлов в бинарной версии (`src/inference/wsi_aggregator.py`, используется как есть на `master`) — редкий, но выраженный признак не должен растворяться в среднем по всему препарату.

Явной тепловой карты/GradCAM для сегментации не нужно — сама маска уже является пространственным объяснением: каждый пиксель промаркирован предсказанным классом, а не скалярной «важностью».
