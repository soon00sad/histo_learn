# Модель

## Обзор

| | |
|---|---|
| Архитектура | EfficientNet-B3 (`timm`) |
| Классы | `benign` (доброкачественная), `malignant` (злокачественная) |
| Вход | RGB 224×224, нормализация по статистикам ImageNet |
| Обучающий датасет | BreakHis, n=7909 |
| AUC-ROC | 0.9953 |
| Accuracy | 97% |
| Устройство инференса | CPU (GPU не требуется) |
| Explainability | GradCAM++ на `model.blocks[-1][-1]` |

Веса (`model.pth`, ~43.3 МБ) распространяются отдельно от кода — скачиваются `scripts/download_weights.py` с HuggingFace в `models/` (каталог вне git).

## Честность в отношении метрик

**AUC-ROC 0.9953 и accuracy 97% получены на BreakHis — датасете одной лаборатории.** Это не клиническая валидация и не гарантия аналогичного качества на препаратах из других лабораторий/сканеров (разная пробоподготовка, окраска, сканеры — см. [ALGORITHMS.md](ALGORITHMS.md), нормализация Macenko частично компенсирует именно этот эффект, но не заменяет валидацию). Целевое значение на клинических данных, заявленное в брифе проекта, — **AUC-ROC ≥ 0.92**; оно ещё не подтверждено на данных, независимых от BreakHis.

Во всех местах интерфейса и PDF-отчёта, где показывается результат модели, обязателен дисклеймер: «Система поддержки принятия решений. Окончательное заключение формулирует врач-патологоанатом» (задаётся в `config/config.yaml` → `app.disclaimer`, используется и на фронтенде, и в PDF).

## Область применения (v1.0)

- Только инвазивная карцинома vs доброкачественная ткань.
- Только H&E-окраска.
- Только рак молочной железы.
- **Вне области:** DCIS (протоковая карцинома in situ), LCIS (дольковая карцинома in situ), метастазы, другие локализации.

## Как воспроизвести/дообучить

Код обучения не входит в этот репозиторий (только инференс) — датасет и обучающий пайплайн описаны здесь для воспроизводимости при необходимости переобучения:

1. **Датасет.** BreakHis (n=7909, бинарная разметка benign/malignant). Для WSI-пайплайна апробация проводилась на CAMELYON16 (тайлинг/фильтрация фона/нормализация — независимы от целевой разметки и переносятся на любой WSI-датасет).
2. **Архитектура.** `timm.create_model("efficientnet_b3", pretrained=True, num_classes=2)` — старт с ImageNet-весов, дообучение на BreakHis.
3. **Препроцессинг обучения** должен совпадать с инференсом: resize 224×224, нормализация ImageNet-статистиками (см. `config/config.yaml` → `model.normalize_mean/std`). При переобучении с другим препроцессингом — обновить эти значения в конфиге, а не в коде.
4. **Замена весов.** Обученный `state_dict` сохранить как `models/model.pth` (или путь из `model.weights_path` в конфиге) в формате, совместимом с `torch.load` + `model.load_state_dict` (см. `src/inference/model.py::load_model`) — обычный `torch.save(model.state_dict(), ...)`.
5. **GradCAM-слой.** Если меняется архитектура (не EfficientNet-B3) — обновить `model.gradcam_target_layer` в конфиге (путь атрибута с числовыми индексами, например `blocks.-1.-1`, резолвится `src/inference/model.py::resolve_target_layer`).

## Ограничения инференса

- CPU-инференс: один патч — секунды; полный WSI-препарат — до ~15 минут (зависит от размера препарата и доли тканевой площади, тайлы фона не проходят через модель — см. ALGORITHMS.md §1–2).
- Модель и GradCAM++-хуки загружаются один раз на процесс (`src/api/ml_runtime.py`) — конкурентный инференс внутри одного процесса не распараллеливается; масштабирование — через несколько worker-процессов.
